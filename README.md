# Cyber GJL releases

Public installers and signed updates for Cyber GJL, a desktop S3 file manager. Application source is maintained separately.

Download installers from [Releases](https://github.com/Greyjuicelab/CyberGJL-Releases/releases). Linux uses AppImage; macOS supports Intel and Apple Silicon; Windows uses NSIS or MSI installers.

The updater feed is `https://github.com/Greyjuicelab/CyberGJL-Releases/releases/latest/download/latest.json`. Update packages are signed with the Cyber GJL updater key. Updater signing is separate from operating-system installer signing.
